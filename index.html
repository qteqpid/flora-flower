新手教程

开局目标

第一次进入会出生在新手地图。这里主要刷 Common 机械蜘蛛，用来练走位、攒基础花瓣和熟悉背包。右下角传送门通往花园，进入花园后不能回新手地图。

移动与攻击

鼠标模式下移动鼠标控制方向，按住鼠标或空格让花瓣张开；左键会同时尝试发射手榴弹、地雷、导弹等可主动释放的花瓣。设置里可以切换 WASD、触屏、反向舒张。

花瓣与背包

背包里的物品可以拖到装备栏。上排是当前装备，下排是备用装备；数字键 1-9 和 0 可以切换对应槽位的上下装备。花瓣等级越高，伤害、耐久、宠物能力等会按等级倍率成长。

合成、锻造、天赋

按 C 打开合成，多个同等级物品可以冲更高等级；按 X 打开锻造，基础花瓣可以和指定材料合成特殊花瓣。升级会给天赋点，V 打开天赋，推荐先点装备栏、血量、回血、转速和磁铁。

地图路线

花园中心是出生腔室，四个方向有不同颜色区域。下水道入口在花园左上附近；下水道里越深入怪物等级越高，死亡后会在下水道入口附近重生。

掉落规则

怪物会掉落自己的掉落表组合。掉落等级大概率比怪物低一档，小概率与怪物同等级。主界面的怪物图鉴可以查看每个怪物、每个等级的血量、攻击和掉落组合概率。
